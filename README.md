# 🔗 Links Saver

A simple and lightweight web application for saving and managing your favorite links directly in your browser.

## 🚀 Live Demo

👉 **[Try Links Saver](https://links-savers.netlify.app/)**

Links Saver lets you save a **title + URL** and quickly access your saved links whenever you return to the application. Your data is stored locally in the browser using **LocalStorage**, so no backend or database is required.

## ✨ Features

* 🔗 Save links with a custom title
* 💾 Store links using browser LocalStorage
* 🔄 Saved links remain after refreshing the page
* 🚀 Open saved links in a new browser tab
* 🗑️ Delete saved links
* 📱 Responsive interface
* 🎨 Clean dark-themed UI
* ⚡ No frameworks or external dependencies

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript**
* **LocalStorage API**

## 🚀 Getting Started

### Clone the repository

```bash

```

### Run the project

No installation or build process is required.

Simply open `index.html` in your browser.

For development, you can use the **Live Server** extension in VS Code.

## 💡 How It Works

Links Saver uses the browser's **LocalStorage API** to store saved links.

When a user saves a link:

1. The title and URL are collected.
2. The information is stored in LocalStorage.
3. The saved link is displayed on the page.
4. The link can be opened directly in a new tab.

Because the data is stored locally, saved links remain available after refreshing the page.

## 🔐 Privacy

Links Saver is a client-side application.

Your saved links are stored locally in your browser. No backend or database is required.

> Clearing the browser's site data or LocalStorage will remove the saved links.
